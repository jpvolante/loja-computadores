## 📖 Sobre o projeto

O **Digital Sarca** é uma aplicação desenvolvida em React para cadastrar e exibir produtos de informática de maneira dinâmica.

Os produtos são organizados em diferentes seções da loja e apresentados em cartões que exibem nome, marca, preço e estado de conservação.

Esta versão recebeu uma identidade visual inspirada em aço e elementos metalizados, combinando tons escuros, prateados e detalhes modernos.

> Projeto acadêmico desenvolvido para a disciplina de Programação para Web II do Instituto Federal de São Paulo — Campus São Carlos.

---

## ✨ Funcionalidades

- Cadastro de produtos de informática;
- seleção de marca e seção;
- classificação como produto novo ou usado;
- exibição dinâmica dos produtos em cartões;
- separação automática dos produtos por seção;
- formatação dos preços em reais;
- validação dos campos do formulário;
- limpeza automática após o cadastro;
- ocultação das seções sem produtos;
- interface responsiva;
- identidade visual metalizada.

## 💻 Como executar localmente

### 1. Clone o repositório

```bash
git clone https://github.com/jpvolante/loja-computadores.git
```

### 2. Entre na pasta do projeto

```bash
cd loja-computadores
```

### 3. Instale as dependências

```bash
npm install
```

### 4. Execute o projeto

```bash
npm run dev
```

Depois, abra no navegador o endereço informado pelo terminal, normalmente:

```text
http://localhost:5173/
```
