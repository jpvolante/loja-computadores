Sobre o projeto

O Digital Sanca é uma aplicação desenvolvida em React para cadastrar e exibir produtos de informática de maneira dinâmica. Os produtos são organizados em diferentes seções da loja e apresentados por meio de cartões contendo nome, marca, preço e estado de conservação.

Funcionalidades
Cadastro de produtos de informática;
seleção da marca do produto;
organização dos produtos por seção;
classificação como produto novo ou usado;
exibição dinâmica dos produtos em cartões;
formatação dos preços em reais;
validação dos campos do formulário;
ocultação das seções que não possuem produtos;
limpeza automática do formulário após o cadastro;
interface responsiva com identidade visual metalizada.
